# Thala 7. — CSS Mini Project (Tutedude)

A responsive 4-page e-commerce website built with HTML, CSS (Flexbox & Grid), and Vanilla JavaScript:

1. **Landing Page (`index.html`)**: Branded Thala 7. header, hero banner, and featured running shoes.
2. **Product Display (`product.html`)**: Main shoe image on left, product details, price (`₹1,334`), Save 12% badge, quantity selector, Add to Cart button, and horizontal scrolling flex gallery.
3. **Shopping Cart (`cart.html`)**: Itemized cart table with quantity controls & remove button, `< Continue Shopping` link, coupon code (`THALA7`), and price breakdown.
4. **Checkout / Payment (`checkout.html`)**: Contact email, Cards/Crypto/Bank payment tabs, card inputs, and Order Summary with Razorpay trust badge.

## How to Upload to GitHub

1. Unzip `thala7-css-mini-project.zip` and open the folder in VS Code or Terminal.
2. Create a new repository on [GitHub](https://github.com/new) (e.g., `thala7-css-mini-project`).
3. Run these commands inside the unzipped folder:
   ```bash
   git init
   git add .
   git commit -m "Add Thala 7 CSS Mini Project"
   git branch -M main
   git remote add origin https://github.com/<your-username>/thala7-css-mini-project.git
   git push -u origin main
   ```
